# 📱 BeFits – Fitness & Health App

BeFits is a simple yet modern fitness and health Android application built with **Kotlin**.  
It helps users track BMI, create personalized exercise schedules, view diet plans, and more — all wrapped in a clean, user-friendly UI.

---

## ✨ Features
- 📊 **BMI Calculator** – Quickly calculate and track your Body Mass Index.
- 🏋️‍♂️ **Exercise Tracker** – Customize weekly workout plans; see exercises for each day with images & details.
- 🍽 **Diet Plan** – Choose between Weight Gain or Weight Loss goals and view recommended diet charts.
- 🙋‍♂️ **Personalization** – Enter your name, age, current weight & target weight once; app greets you every time.
- 🎨 **Modern UI** – Simple, attractive interface for easy navigation.

## 📝 How It Works
On first launch, app asks for your name, age, current & target weight, and saves them locally.

BMI calculator helps track your fitness.

Exercise Tracker shows daily exercises with images.

Diet Plan displays charts based on your selected goal.

## 📌 Notes
The app asks user details only once on the first launch.

Splash screen removed for faster startup.

Images for exercises & diet charts should be placed inside res/drawable.
